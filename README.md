# SAM3 视频目标标注工具（网页版）

基于 [SAM3 (Segment Anything Model 3)](https://github.com/facebookresearch/sam3) 的视频目标跟踪标注工具，采用 Flask 提供网页界面。在浏览器中通过**绘制多边形**完成目标标注（自动生成正/负样本点），经 SAM3 传播跟踪、人工微调后，导出 YOLO 格式数据集。

## 功能特性

- **多边形标注**：在视频帧上绘制多边形圈定目标，支持任意顶点数、多目标、逐顶点撤销
- **样本点自动生成**：多边形闭合后自动生成 8 个正样本点 + 8 个负样本点，作为 SAM3 的点 prompt
- **视频管理**：扫描 `videos/` 目录选择视频、输入绝对路径打开、上传本地视频（最大 4GB）
- **帧导航**：帧滑块、跳转输入、±1 / ±10 帧步进；自动校正损坏视频的元数据帧数
- **SAM3 跟踪**：选择 GPU 异步加载模型，多目标点 prompt 双向传播，实时进度显示
- **跟踪框修正**：在画面上拖动检测框（整体移动 + 8 方向缩放手柄），逐帧保存修正结果
- **项目管理**：标注项目保存/加载（JSON），含标注、类别映射、视频路径信息
- **YOLO 导出**：导出 images / labels / classes.txt / config.json 完整数据集，支持自定义类别名
- **前端零依赖**：单页 HTML + Canvas 实现，无任何外部 CDN 引用，可离线部署

## 多边形标注（核心功能）

### 标注交互

1. 点击左侧"**📌 开始标注新目标**"进入标注模式，系统自动分配目标 ID（从 3 开始递增，同一 ID 对应固定颜色）
2. 在画面上**依次左键点击**添加多边形顶点，实时显示顶点数与虚线轮廓
3. 闭合多边形（三种方式任选）：
   - **点击起点附近**（12px 容差，起点会高亮提示）
   - **双击**画布
   - **回车键**
4. 闭合后自动生成样本点并保存该目标（至少需要 3 个顶点）

| 操作 | 效果 |
|---|---|
| 左键点击 | 添加一个多边形顶点 |
| 右键点击 | 撤销上一个顶点 |
| `Esc` / "🗑 清空" | 取消当前正在绘制的多边形 |
| 回车 / 双击 / 点击起点 | 闭合多边形（≥3 顶点时可用） |
| "↶ 撤销" | 撤销上一个顶点 |
| "✅ 保存并标注下一个" | 保存当前目标并立即开始标注下一个 |

绘制过程中鼠标移动显示预览线，已保存的多边形以半透明填充 + 同色虚线描边回显，可在左侧"已标注目标"列表中查看或删除目标。

### 正/负样本点自动生成

多边形闭合后，前端自动计算 16 个样本点（作为 SAM3 的点击 prompt）：

- **8 个正样本点**（label=1）：在多边形包围盒内生成网格候选点（不足时逐步加密），用最远点采样算法从靠近质心的点开始挑选，保证点尽量均匀分布在多边形内部
- **8 个负样本点**（label=0）：从多边形质心向 8 个方向发射射线，求与多边形边界的最远交点，再向外推一段距离（`max(15px, 0.2 × 包围盒长边)`），得到紧贴目标外部的采样点，并裁剪到图像范围内

> 提示：跟踪实际使用的是这些正/负样本点（点 prompt），多边形轮廓（`polygon` 字段）保存在标注中用于回显与项目管理。

## 界面说明

- **顶部工具栏**：视频选择/打开/上传、项目保存/加载、GPU 选择与模型加载、"运行跟踪"、"导出YOLO"
- **左侧边栏**：视频信息、帧导航（滑块 + 步进）、标注控制（多边形操作按钮 + 快捷键提示）、已标注目标列表、类别设置
- **右侧画布**：帧画面（含标注与跟踪框叠层）、"显示跟踪结果"切换、跟踪进度条
- **底部状态栏**：操作反馈与错误提示

## 目录结构

```
.
├── app.py                  # Flask 后端（全部逻辑：帧读取、跟踪、导出、项目存取）
├── start_web.sh            # 启动脚本
├── templates/
│   └── index.html          # 前端页面（自包含，无外部 CDN 依赖）
├── model/                  # 模型权重目录（需自行下载，已 gitignore）
│   ├── sam3.pt
│   └── bpe_simple_vocab_16e6.txt.gz
├── videos/                 # 视频目录（上传的视频保存在 videos/uploads/）
├── projects/               # 标注项目保存目录（运行时自动创建）
└── exports/                # YOLO 导出目录（运行时自动创建）
```

## 环境要求

- Linux + NVIDIA GPU（需 CUDA）
- Python 3.10+（本项目验证于 Python 3.12）
- 已安装 [SAM3 官方包](https://github.com/facebookresearch/sam3)
- SAM3 模型权重（见下文获取方式）

## 安装

### 1. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

torch 建议按显卡 CUDA 版本安装官方包，例如：

```bash
pip install torch==2.7.0 torchvision --index-url https://download.pytorch.org/whl/cu126
```

### 2. 安装 SAM3 官方包

```bash
git clone https://github.com/facebookresearch/sam3.git
cd sam3 && pip install -e .
```

### 3. 下载模型权重

SAM3 权重需在 Hugging Face 申请访问权限：[facebook/sam3](https://huggingface.co/facebook/sam3)（同意协议并通过后，登录 Hugging Face 下载）。将以下文件放入本仓库 `model/` 目录：

| 文件 | 说明 |
|---|---|
| `sam3.pt` | 模型权重，约 3.3GB（未包含在本仓库中） |
| `bpe_simple_vocab_16e6.txt.gz` | BPE 词表（也可从 SAM3 官方仓库获取） |

## 启动

```bash
# 方式一：激活已装好 sam3 的 conda 环境后直接启动
conda activate sam3
./start_web.sh

# 方式二：指定 Python 解释器
SAM3_PYTHON=/path/to/envs/sam3/bin/python ./start_web.sh

# 方式三：直接用 python 运行
python app.py
```

默认监听 `0.0.0.0:9930`，浏览器打开 `http://<服务器IP>:9930` 即可使用。

### 可配置项

模型权重、BPE 词表、视频目录的取值优先级（从高到低）：

**命令行参数 > 环境变量 > 默认路径（相对仓库根目录）**

| 命令行参数 | 环境变量 | 默认值 |
|---|---|---|
| `--checkpoint` | `SAM3_CHECKPOINT` | `model/sam3.pt` |
| `--bpe` | `SAM3_BPE` | `model/bpe_simple_vocab_16e6.txt.gz` |
| `--videos-dir` | `SAM3_VIDEOS_DIR` | `videos/` |
| `--host` / `--port` | — | `0.0.0.0` / `9930` |

示例：

```bash
./start_web.sh --port 8080 --checkpoint /data/models/sam3.pt
```

## 使用流程

1. **打开视频**：从下拉框选择 `videos/` 目录中的视频，或输入绝对路径，或点击"上传视频"上传本地文件
2. **浏览帧**：使用滑块 / 跳转 / 步进按钮定位到包含目标的帧
3. **绘制多边形标注**：点击"开始标注新目标" → 围绕每个目标依次点击顶点 → 双击/回车/点击起点闭合，自动生成 8 正 + 8 负样本点；重复此步骤标注所有目标
4. **加载模型**：选择 GPU，点击"加载SAM3模型"（异步加载，状态栏显示进度）
5. **运行跟踪**：点击"运行跟踪"，SAM3 从最早标注帧开始双向传播，进度条实时显示；完成后勾选"显示跟踪结果"查看
6. **修正结果**：在跟踪视图下直接拖动检测框（移动/缩放手柄）微调，自动逐帧保存
7. **保存与导出**：可随时"保存项目"；确认结果后点击"导出YOLO"，在弹窗中为每个目标填写类别名，导出数据集到 `exports/<名称>/`

## 导出内容

```
exports/<名称>/
├── images/                  # 含检测框的帧图像（JPG）
├── labels/                  # YOLO 格式标签（class_id x_center y_center w h，归一化）
├── classes.txt              # 类别名列表（行号即 class_id，未命名用 class_N 占位）
└── <视频名>_config.json     # 导出配置（视频信息、目标列表、类别映射）
```

## 数据与坐标约定

| 数据 | 坐标格式 | 说明 |
|---|---|---|
| 标注多边形 `polygon` | 像素坐标顶点序列 | `[[x, y], ...]`，用于回显 |
| 标注样本点 `points` | 像素坐标 | 前 8 个为正样本（label=1），后 8 个为负样本（label=0） |
| 跟踪结果 `track_results` | 归一化相对坐标 | `[obj_id, x, y, w, h]`，0~1，x/y 为框左上角 |
| YOLO 标签 | 归一化中心点格式 | `class_id x_center y_center w h` |

## 注意事项

- 标注项目保存在 `projects/<名称>.json`，与视频路径解耦：加载项目时若视频不存在会给出提示，标注仍可恢复
- app.py 启动时会将 `TMPDIR` 指向仓库内 `_tmp/` 目录（在 import 库之前设置），避免根分区空间不足导致上传临时文件失败；如需其他位置可直接修改代码顶部常量
- 加载模型与运行跟踪需要可用的 CUDA GPU；模型加载前的标注操作不受影响
- 视频元数据帧数不可靠（录制/转码中断）时，后端会从末尾向前探测最多 300 帧校正实际帧数
